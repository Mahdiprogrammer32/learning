# دایرةالمعارف جامع مهندسی نرم‌افزار ARTIN

این مخزن، نسخهٔ عملی و پروژه‌محور از نقشهٔ راه آموزش مهندسی نرم‌افزار است که بر اساس اصول طراحی سیستم، تمرین واقعی، امنیت، کیفیت کد، استقرار و تصمیم‌گیری فنی شکل گرفته است.

هدف اصلی این مجموعه این نیست که فقط زبان‌هایی مثل PHP، JavaScript یا React را معرفی کند؛ هدف این است که فردی تربیت شود که بتواند:

- مسئله را تحلیل کند
- معماری مناسب طراحی کند
- کد را به‌صورت تمیز و قابل نگهداری بنویسد
- تست، امنیت و پایایی را در نظر بگیرد
- سرویس را مستقر و نگهداری کند
- دربارهٔ تصمیم‌های فنی به‌صورت حرفه‌ای دفاع کند

## فلسفهٔ کتاب

محتوای این مخزن بر پایهٔ اصول زیر ساخته شده است:

1. آموزش عمیق به‌جای فهرست‌نویسی
2. یادگیری از صفر تا سطح مهندسی Production
3. آموزش کدنویسی و معماری به‌صورت پروژه‌محور
4. استفاده از استانداردهای واقعی و مستندات رسمی
5. تمرکز بر تصمیم‌گیری، امنیت، ابعاد عملی و قابلیت نگهداری

## جمع‌بندی
